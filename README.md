# Battle Motion 予習ツール

攻略記事の戦術を「場面ごと・ジョブごと」に整理し、YouTubeの討伐動画と手動で時刻合わせして予習するローカルWebツール。
ボスごとのデータ（Battle Pack）を追加すれば、オデシージェールの他のボスや他コンテンツにも使える。

## 起動
```bash
python -m http.server 8765 --bind 127.0.0.1
```
このフォルダで実行し、ブラウザで http://127.0.0.1:8765/ を開く（`file://` では動かない）。

## LSメンバー向けの使い方
1. 上の「あなたのジョブ」で自分のジョブを選ぶ
2. 「動画を読み込む」で再生（読み込まなくても下の図だけ再生できる）
3. 「いまの場面」の **あなたのやること** と、下の **やること一覧**（印刷/PDF可）を見る

出典の印：`記事`＝攻略記事に記載／`映像`＝動画で目視確認／`演出用`＝説明用の仮定／`未確認`。
図の位置・HP・秒数はすべて演出用。動画との対応は、人が登録した同期点の間だけ動き、範囲外は「未同期区間」と表示する。

## 編集者（同期点の登録）
1. 動画を再生し、場面が始まった瞬間で一時停止
2. 「動画との同期を編集する」で場面を選び、「映像で確認した／仮置き」を選んで「この時刻を登録」
3. 2点以上で追従開始。終わったら「JSONで保存」→ `sync/<battleId>.<videoId>.json` を置き換えて配布

編集内容はまずその端末のブラウザに保存される。「同梱データに戻す」で破棄できる。

## 構成
| ファイル | 役割 |
|---|---|
| `index.html` / `app.js` | UI |
| `sync-engine.js` | 同期計算（純関数） |
| `battles/index.json` | 戦闘の目録（選択肢に出る） |
| `battles/*.json` | Battle Pack（戦闘の中身） |
| `battles/_template.json` | 新規作成用の雛形 |
| `sync/*.json` | 動画ごとの同期点（配布用） |
| `schema.md` | データ仕様 |
| `tests/sync-engine.test.js` | `node tests/sync-engine.test.js` |
